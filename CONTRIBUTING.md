# Contributing

This is a personal portfolio, and the code and media are all rights reserved (see [LICENSE](LICENSE)). I am not accepting code or content contributions, and pull requests will be closed unless we have agreed them first.

What is welcome:

- **Bug reports:** a broken link, a demo that fails to load, a layout problem. Open an issue and include your browser, your operating system and what you expected to see.
- **Corrections:** a typo or factual error on the page. Open an issue quoting the text.

If you would like to reuse something here, email tim_jones175@icloud.com first.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
