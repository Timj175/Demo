# Security policy

This repository is a static portfolio site with no server, database or login. It holds no secrets, and the demos run in your browser with invented sample data.

## Reporting a problem

If you find something that should not be public (a credential, a personal detail, or confidential material), please do not open a public issue. Email **tim_jones175@icloud.com** with the file path and what you saw. I will remove it and reply as soon as I can.

For ordinary bugs such as a broken link or a demo that does not load, a normal GitHub issue is fine.

## Supported versions

Only the current `main` branch and the live site are maintained.
